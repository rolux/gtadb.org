gtadb.org

api.gtadb.org

Overview

api.gtadb.org provides a suite of map and geo service APIs for GTA IV, V and VI.

Plain HTTP/GET unless otherwise stated.

Current status: experimental.

GTADB Elevation API

Get the elevation at a given point:

https://api.gtadb.org/elevation?gta=6&x=-3778.98&y=712.94&key=API_KEY

{
    "results": [
        {
            "elevation": 3.246,
            "location": [-3778.98, 712.94]
        }
    ],
    "status": "OK"
}

GTADB Geocoding API

Get structured geodata for a given query:

https://api.gtadb.org/geocode?gta=6&address=lombank&key=API_KEY

Get structured geodata for a given point:

https://api.gtadb.org/geocode?gta=6&x=-700&y=1200&key=API_KEY

GTADB Landmarks API

Get all landmarks:

https://api.gtadb.org/landmarks?gta=6&key=API_KEY

{
    "results": [
        {"id": "L1", "ig_coordinates": [1409.401, 2803.214], "types": ["hotel"]},
        {"id": "L2", "ig_coordinates": [1491.645, 2633.302], "types": ["residential"]},
        {"id": "L3", "ig_coordinates": [1541.925, 2562.866], "types": ["hotel"]},
        [...]
    ],
    "status": "OK"
}

https://api.gtadb.org/landmarks?gta=6&id=L25&key=API_KEY

GTADB Static Maps API

Get a static map image with a given center (in world coordinates), size (in pixels) and scale (in pixels per meter):

https://api.gtadb.org/staticmap?gta=6&x=0&y=0&w=1000&h=1000&scale=0.5&key=API_KEY
